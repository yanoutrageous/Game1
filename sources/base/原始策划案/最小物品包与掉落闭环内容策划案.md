# M3：最小物品包与掉落闭环内容策划案 v0.2

## 0. 阶段定位

M3 的正式定位是：

```text
最小物品包 + 掉落闭环
```

M3 不是完整长期系统，不是完整抽奖系统，不是完整天赋树，不是完整事件池，也不是完整难度系统。

M3 的目标是让以下链路成立：

```text
局内内容产生掉落
→ 掉落进入 GroundLoot
→ 玩家拾取进入背包
→ 背包受到负重限制
→ 玩家可使用、丢弃、替换、保留
→ 成功撤离写入仓库
→ 失败按抢救负重保留部分物品
→ 旅商可将风险资产转为安全收益
→ 仓库、申领、出勤配置获得实际内容基础
```

M3 只解决“物品为什么存在、从哪里来、到哪里去、怎么结算”的首批闭环。

---

# 1. M3 规则边界

## 1.1 M3 必须遵守的规则

```text
1. 唯一物只通过抽奖获得。
2. M3 普通掉落只覆盖 1-6 级藏品。
3. 7 级唯一物不进入搜索、宝箱、怪物、祭坛、普通事件掉落。
4. 失败保底按抢救负重 / 抢救容量处理，不默认按 1 件。
5. 本局黑币、安全收益、长期金币必须区分。
6. 局内获得装备 = 未登记装备，不是藏品。
7. 作业装备、作业消耗品、藏品、特殊物不能混类。
8. 天赋可以进入 M3，但只做与物品闭环相关的少量基础天赋。
9. 资历 / 许可只保留 50 级扩展接口，不展开完整等级表。
10. 协议难度矩阵只作为接口，不在 M3 做完整难度系统。
11. 掉落系统必须接 GroundLoot / 背包 / 仓库 / 结算。
```

## 1.2 M3 不做的内容

```text
完整 50 级资历表
完整 50 级许可表
完整抽奖流程
完整唯一物收藏系统
完整图鉴
完整研究
完整装备强化
完整消耗品商店经济
完整天赋树 UI
Boss
多地图
完整高难委托
完整事件池
完整难度平衡
```

这些不是被取消，只是不属于 M3 P0。

# 2. 资源与收益结构

## 2.1 本局黑币

本局黑币是局内待结算收益。

来源：

```text
搜索
宝箱
怪物
赌徒 / 概率装置
祭坛
事件
Debug
```

规则：

```text
成功撤离后转入长期金币；
失败默认丢失；
不占背包负重；
不可主动丢弃；
不等同于长期金币。
```

玩家理解：

```text
这笔收益还没安全。撤离后才算真正到账。
```

---

## 2.2 安全收益

安全收益是本局中已锁定的收益。

首批来源：

```text
旅商出售背包物品
```

规则：

```text
成功撤离后写入长期金币；
失败后也写入长期金币；
不占背包负重；
作为结算明细单独展示。
```

玩家理解：

```text
少赚一点，但已经安全。
```

注意：

```text
安全收益不直接等同长期金币。
它是在结算时写入长期金币的“已锁定收益”。
```

---

## 2.3 长期金币

长期金币是局外账户资源。

用途：

```text
后勤申领
购买作业消耗品
购买作业装备
后续研究 / 抽奖 / 许可相关消费
```

M3 中只需要保证：

```text
成功撤离可写入；
失败时安全收益可写入；
本局黑币失败时不写入。
```

---

## 2.4 背包物资

背包物资包括：

```text
藏品
作业消耗品
未登记装备
特殊物
```

规则：

```text
占用背包负重；
成功撤离后进入仓库；
失败时按抢救负重保留部分；
未保留物资丢失；
放弃 / 中止默认不带回。
```

# 3. 物品主分类

## 3.1 作业装备

作业装备是出发前配置、局内持续生效的物品。

规则：

```text
出发前装备才生效；
局内获得的装备不立即生效；
局内获得装备进入背包时标记为“未登记装备”；
成功撤离后进入仓库；
下次出勤前配置后才生效。
```

局内获得装备的正确分类：

```text
物品类型：作业装备
登记状态：未登记
局内是否生效：否
成功撤离后：进入后勤仓库
```

禁止写法：

```text
局内获得装备作为异常回收物处理
```

如果某件旧物“看起来像装备”，但设计上不能配置，则应归入藏品，而不是装备。

---

## 3.2 作业消耗品

作业消耗品是局内可使用的一次性物品。

规则：

```text
可出发前带入；
可局内获得；
使用后消耗；
未使用且成功撤离可带回仓库；
失败时可被抢救负重保留；
使用后的消耗品不返还。
```

---

## 3.3 藏品 / 异常回收物

“藏品”是系统分类。
“异常回收物”是玩家可见名称。

规则：

```text
通常不产生局内即时效果；
主要用于出售、收藏、图鉴、研究、节点任务或事件要求；
可进入背包；
可占用负重；
成功撤离后进入仓库；
失败时可被抢救负重保留；
可卖给旅商或后勤；
不自动转化为长期金币。
```

---

## 3.4 特殊物

特殊物是任务物、许可物、钥匙物、抽奖凭证、研究样本、地图规则物等。

M3 处理：

```text
只预留分类和少量接口；
不作为 P0 掉落主内容；
不展开完整特殊物系统；
不要求实现抽奖凭证掉落。
```

M3 可记录的特殊物方向：

```text
许可证明片
档案残页
抽奖凭证
异常指令片
```

其中：

```text
抽奖凭证 = P1/P2 接口
不是 M3 P0 必须内容
```

# 5. 物品基础字段要求

M3 不写正式工程 ID，但策划上必须要求后续每个物品具备以下字段。

## 5.1 必备字段

```text
名称
物品类型
藏品等级 / 装备等级 / 消耗品等级
baseValue
weight
是否可堆叠
是否可出售
是否可丢弃
是否可局内使用
是否可出发带入
是否可入仓
来源限制
失败抢救规则
唯一物规则
```

## 5.2 baseValue 与等级关系

```text
藏品等级 ≠ baseValue
藏品等级 ≠ 唯一性
baseValue 用于出售、结算、仓库排序、失败抢救排序
藏品等级用于显示、掉落稀有度、收藏层级
来源规则用于限制获得路径
unique_policy 用于唯一物保护
```

正确理解：

```text
唯一物一定是 7 级；
但高价值物不一定是唯一物；
6 级可以很贵，但仍不是唯一物；
低等级物也可以因任务或事件具有特殊用途。
```

# 8. 天赋首批内容

M3 接入天赋概念，但不做完整天赋树。
P0 只做与物品、掉落、背包、旅商、协议直接相关的 8 个基础天赋方向。

## 8.1 八区扫描增强

类型：

```text
信息类天赋
```

效果：

```text
当前格周围 8 区信息面板显示：
- 已探索
- 已扫描
- 已标记
- 已清理
- 未知
```

不显示：

```text
未被扫描的雷险答案
未被发现的房型答案
```

---

## 8.2 工伤适应

类型：

```text
雷险类天赋
```

效果：

```text
雷险伤害降低。
```

---

## 8.3 第一次算意外

类型：

```text
雷险容错天赋
```

效果：

```text
每局首次雷险伤害降低或免疫。
仅触发一次。
```

---

## 8.4 超载许可

类型：

```text
背包类天赋
```

效果：

```text
提高回收包负重上限。
```

---

## 8.5 抢救条款

类型：

```text
失败保底类天赋
```

效果：

```text
提高失败抢救负重；
或允许额外抢救一个低负重物品。
```

```text
失败多带 1 件
```

类型：

效果：


```text

```

具体数值后续数值案填写。

## 8.7 信标嗅觉

类型：

```text

```

效果必须明确。

可选效果：


## 8.8 协议耐受

```text
协议类天赋
```

效果：

## 14.1 狐狸旅商

定位：

```text

出售背包物品。
```


```text

```

```text

唯一物不能普通出售；
```

```text
不能使用长期金币下注；
不能借贷；
胜利所得仍是本局黑币，不直接进入长期金币。
```

结果类型：

```text
亏损本局黑币；
获得本局黑币；
获得 1-3 级藏品；
协议压力变化；
小概率获得临时状态。
```

## 14.3 临时祭坛

```text
生命换递增收益的贪心事件。
```

规则：

```text

奖励递增；
最低保留 1 HP；
不直接产出唯一物；
不额外增加压力，除非高难 modifier。
```

奖励范围：

```text
第 1 段：本局黑币 + 1-2 级藏品
第 2 段：本局黑币 + 2-3 级藏品
第 3 段：本局黑币 + 3-4 级藏品
第 4 段：4-5 级藏品
第 5 段：5-6 级藏品
```

# 15. GroundLoot / 背包 / 仓库闭环

## 15.1 掉落生成

所有物品型掉落默认先进入：

```text
GroundLoot
```

包括：

```text
搜索掉落
宝箱掉落
怪物掉落
事件奖励
祭坛奖励
玩家主动丢弃物
背包替换掉落物
Debug 生成物
```

## 15.2 拾取

拾取规则：

```text
检查背包负重；
检查物品是否可拾取；
拾取后进入背包；
GroundLoot 中移除；
若背包负重不足，提示无法拾取；
后续可支持替换 / 丢弃。
```

## 15.3 使用

可使用物品：

```text
作业消耗品
部分特殊物
```

不可使用物品：

```text
普通藏品
未登记装备
唯一物
```

使用后：

```text
消耗品从背包移除；
产生对应效果；
记录 RunLog。
```

## 15.4 丢弃

普通物品：

```text
可主动丢弃；
丢弃后进入当前房间 GroundLoot；
本局结束未拾取则丢失。
```

不可普通丢弃：

```text
唯一物
关键特殊物
锁定任务物
```

M3 中唯一物不进入普通局内掉落，因此仅保留规则。

## 15.5 成功撤离

处理：

```text
本局黑币 → 长期金币；
安全收益 → 长期金币；
背包内藏品 → 仓库；
背包内未使用消耗品 → 仓库；
背包内未登记装备 → 仓库装备；
背包内特殊物 → 对应系统或仓库；
临时状态清除；
临时攻击成长清除；
协议压力清除。
```

## 15.6 失败

正式规则：

```text
本局黑币丢失；
安全收益写入长期金币；
背包物资按抢救负重保留；
保留物进入仓库；
未保留物丢失；
临时状态清除；
临时攻击成长清除；
协议压力清除。
```

抢救规则：

```text
以抢救负重 / 抢救容量为主；
不是默认 1 件；
可由天赋、许可、保险、特殊物调整。
```

若 UI 暂未完成，可临时自动选择：

```text
在抢救负重限制内，按 baseValue 优先选择组合。
```

注意：

```text
这只是 UI 简化，不是规则改成“1 件”。
```

## 15.7 放弃 / 中止

处理：

```text
不算成功撤离；
不等同死亡失败；
本局黑币默认不转化；
背包物默认不带回；
安全收益是否保留由后续规则决定；
Debug 路径需明确标记。
```

# 20. M3 验收标准

M3 完成后，玩家应能理解并体验：

```text
装备、消耗品、藏品、特殊物的区别；
物品有重量和价值；
搜索、宝箱、怪物、事件能产生不同掉落；
掉落先进入 GroundLoot；
拾取进入背包；
背包受负重限制；
消耗品能使用；
藏品能带回或出售；
未登记装备不会立即生效；
成功撤离能把背包物写入仓库；
失败按抢救负重保留部分物品；
旅商能把风险资产转为安全收益；
宝箱比普通搜索更有价值；
怪物主要提供战斗成长，不是主要经济来源；
唯一物不会从普通掉落出现；
天赋能影响物品闭环；
协议惩罚由难度接口控制；
资历 / 许可保留长期扩展空间，但不在 M3 展开完整系统。
```

一句话验收：

```text
M3 后，玩家不只是能捡东西，而是能理解这些东西为什么有风险、为什么要带走、为什么要卖、为什么撤离才算真正兑现。
```
