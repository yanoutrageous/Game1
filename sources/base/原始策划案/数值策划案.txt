# 《灰尾回收 / 五四三二一》数值策划案

> 版本定位：48H Game Jam 当前原型数值整理版
> 适用范围：评委模式与标准模式的数值规则、收益结构、协议压力、战斗成长、事件收益、结算规则
> 当前重点：不改地图结构，不改撤离点逻辑，不改房间分布，以现有原型机制为基础进行数值收束

---

## 0. 文档目标

本文档用于统一当前版本的数值设计口径，重点解决以下问题：

1. 结算币是全局资产，因此不能在局内大量直接产出；
2. 普通搜索收益过高，导致宝箱房、事件房和撤离决策价值被稀释；
3. 当前协议下降过快，不利于玩家探索；
4. 搜索不应轻易提升攻击力，否则会导致局内数值膨胀；
5. 怪物应承担“战斗成长”功能，而非主要经济产出功能；
6. 旅商、赌徒、祭坛需要形成差异化风险收益；
7. 失败结算应以背包物资选择为核心，强化撤离价值。

---

# 1. 核心数值设计原则

## 1.1 资源原则

结算币是全局资产，必须谨慎投放。

当前版本不建议让普通搜索、宝箱、怪物、事件直接稳定大量产出全局结算币。

局内收益应以以下形式为主：

| 收益类型  | 定位                     |
| ----- | ---------------------- |
| 待结算币  | 局内临时收益，成功撤离后转入全局       |
| 安全结算币 | 已锁定收益，失败后也可保留          |
| 背包物资  | 回收物、装备、消耗品、异常物，成功撤离后带回 |
| 攻击力成长 | 主要来自击败怪物               |
| 压力变化  | 由探索、踩雷、击败怪物等行为动态改变     |

---

## 1.2 局内行为分工

| 行为    | 主要收益           | 主要代价          |
| ----- | -------------- | ------------- |
| 探索未知格 | 地图信息、发现房间      | +2 压力         |
| 普通搜索  | 少量待结算币、低概率低值物资 | 时间成本、深入风险     |
| 开宝箱   | 高价值物资、少量待结算币   | 通常无压力         |
| 击败怪物  | 攻击力成长、少量物资     | +5 压力、战斗风险    |
| 踩雷    | 无收益            | -30 生命，+10 压力 |
| 旅商出售  | 折价锁定安全收益       | 损失 25% 物品价值   |
| 赌徒    | 高波动待结算币        | 高概率亏损         |
| 祭坛    | 递增收益           | 递增生命消耗        |
| 成功撤离  | 全部收益带出         | 结束本局          |
| 失败    | 仅保留有限物资        | 大量收益损失        |

---

# 2. 资源与货币结构

## 2.1 资源类型

| 类型     | 说明                |   是否立即进入全局 |
| ------ | ----------------- | ---------: |
| 待结算币   | 局内获得的临时结算币        |          否 |
| 安全结算币  | 旅商出售等方式锁定的收益      |   是 / 失败保留 |
| 背包物资   | 回收物、装备、消耗品、异常物    |          否 |
| 全局结算币  | 局外商店、装备、天赋使用的货币   |          是 |
| 物品基础价值 | 每个物品自身的 baseValue | 用于出售、结算、排序 |

---

## 2.2 成功与失败时的资源处理

| 结算情况 | 待结算币      | 安全结算币   | 背包物资     |
| ---- | --------- | ------- | -------- |
| 成功撤离 | 100% 转入全局 | 保留      | 全部带回仓库   |
| 失败   | 丢失        | 保留      | 选择 1 件带回 |
| 旅商出售 | 不涉及       | 获得安全结算币 | 消耗被出售物品  |

---

## 2.3 实现建议

若当前代码暂时不方便区分“待结算币”和“安全结算币”，至少应做到：

1. 降低所有局内直接金币产出；
2. 失败时不保留局内金币，或只保留旅商出售所得；
3. 成功撤离时再将局内金币写入全局；
4. 所有物品增加 `baseValue` 字段，用于旅商出售和失败自动选择。

# 3. 玩家基础数值

| 项目          |  数值 |
| ----------- | --: |
| 玩家最大生命      | 100 |
| 初始生命        | 100 |
| 初始攻击力       |  10 |
| 普通搜索攻击力提升   |   0 |
| 击败怪物攻击力提升   |  +1 |
| 单局击杀攻击力成长上限 |  +5 |
| 雷险伤害        |  30 |
| 雷险是否重复触发    |   否 |
| 雷险是否直接失败    |   否 |

---

## 3.1 雷险容错

| 踩雷次数 | 剩余生命 |
| ---: | ---: |
|  1 次 |   70 |
|  2 次 |   40 |
|  3 次 |   10 |
|  4 次 |   失败 |

雷伤 30 的意义：

1. 玩家不会因一次踩雷直接失败；
2. 第三次踩雷后进入强撤离状态；
3. 雷险既是生命惩罚，也是协议压力惩罚；
4. 相比 25 伤害，30 更能让踩雷产生明确决策压力。

# 4. 协议压力系统

## 4.1 压力变化规则

| 行为     |     压力变化 |
| ------ | -------: |
| 探索未知格  |       +2 |
| 开宝箱    |       +0 |
| 击败怪物   |       +5 |
| 踩雷     |      +10 |
| 使用减压道具 | -6 / -10 |
| 特殊减压事件 |      -15 |
| 压力下限   |        0 |
| 压力上限   |      100 |

压力变化统一使用：

```text
pressure = clamp(pressure + delta, 0, 100)
```

---

## 4.2 协议等级区间

|   压力区间 | 协议等级 | 阶段定位 |
| -----: | ---: | ---- |
|   0~19 |    5 | 正常作业 |
|  20~39 |    4 | 轻度警戒 |
|  40~59 |    3 | 风险作业 |
|  60~79 |    2 | 返程建议 |
| 80~100 |    1 | 最终建议 |

---

## 4.3 节奏预期

| 行为组合                     | 压力结果 | 协议 |
| ------------------------ | ---: | -: |
| 探索 10 个未知格               |   20 |  4 |
| 探索 20 个未知格               |   40 |  3 |
| 探索 20 格 + 击败 2 怪 + 踩 1 雷 |   60 |  2 |
| 探索 30 格 + 击败 3 怪 + 踩 2 雷 |   95 |  1 |

---

## 4.4 协议 1 处理

当前版本不建议协议 1 后继续探索额外扣血。

理由：

1. 探索、战斗、踩雷已经会持续提高压力；
2. 雷险伤害提高到 30 后，本身已有足够威胁；
3. 额外扣血会重新压制玩家探索欲；
4. 协议 1 应先作为强警告状态，而不是硬性死亡倒计时。

协议 1 的主要表现建议：

| 表现 | 建议        |
| -- | --------- |
| UI | 红色警报、数字放大 |
| 音效 | 降级警报      |
| 文案 | 强烈建议返程    |
| 机制 | 暂不额外扣血    |

---

# 5. 战斗与怪物数值

## 5.1 战斗成长原则

普通搜索不再提升攻击力。

攻击力成长主要来自击败怪物。

| 来源   |       是否提升攻击力 |
| ---- | ------------: |
| 普通搜索 |             否 |
| 宝箱   |   否，除非掉落临时消耗品 |
| 击败怪物 |             是 |
| 装备   |             是 |
| 天赋   |        后续单独调整 |
| 事件   | 可少量特殊提供，但需有代价 |

---

## 5.2 怪物基础数值

当前版本只有一种怪物，因此通过数值随机浮动制造差异。

| 项目        |          数值 |
| --------- | ----------: |
| 怪物生命      |       26~38 |
| 怪物攻击伤害    |        8~14 |
| 怪物攻击预警    |       0.8 秒 |
| 怪物攻击间隔    |   2.8~3.4 秒 |
| 玩家攻击冷却    | 0.45~0.55 秒 |
| 击败怪物压力    |          +5 |
| 击败怪物攻击力提升 |          +1 |
| 击败怪物金币    |    0~3 待结算币 |
| 击败怪物掉物概率  |         15% |
| 高强度怪掉物概率  |         25% |

---

## 5.3 怪物奖励结构

怪物的主奖励是攻击力成长，而不是金币。

| 奖励类型 | 处理         |
| ---- | ---------- |
| 攻击力  | 必给，+1      |
| 待结算币 | 少量，0~3     |
| 回收物  | 小概率        |
| 高价值物 | 不建议普通怪稳定掉落 |

---

## 5.4 击杀成长上限

```text
单局通过击败怪物获得的攻击力提升上限为 +5
```

设计目的：

1. 防止击杀滚雪球过强；
2. 保持怪物后续仍有威胁；
3. 避免玩家通过清怪彻底碾压地图；
4. 让战斗成长有爽感，但不破坏整体风险。

---

# 6. 普通搜索收益

## 6.1 普通搜索定位

普通搜索定位为：

> 小额反馈 + 低概率低值物资 + 少量风险回报。

普通搜索不应成为主要经济来源，也不应产出大量全局货币。

---

## 6.2 普通搜索待结算币

推荐公式：

```text
普通搜索待结算币 = random(0, 2) + floor(周围雷数 / 2)
最高不超过 4
```

| 周围雷数 | 待结算币范围 |
| ---: | -----: |
|    0 |    0~2 |
|    1 |    0~2 |
|    2 |    1~3 |
|    3 |    1~3 |
|    4 |    2~4 |

---

## 6.3 普通搜索掉落表

| 结果    |  概率 |   价值区间 |
| ----- | --: | -----: |
| 不掉物品  | 55% |      - |
| 低值回收物 | 35% |    3~8 |
| 普通回收物 |  8% |  10~25 |
| 稀有回收物 |  2% | 40~100 |
| 珍贵及以上 |  0% |      - |

---

## 6.4 高雷数修正

| 条件      | 修正                           |
| ------- | ---------------------------- |
| 周围雷数 ≥3 | 不掉物品 -5%，普通回收物 +3%，稀有回收物 +2% |
| 周围雷数 ≥4 | 稀有回收物额外 +1%                  |

普通搜索不建议掉落珍贵 / 异常物。
珍贵及以上物品应主要来自宝箱、祭坛、特殊事件。

---

# 7. 宝箱收益

## 7.1 宝箱定位

宝箱房定位为：

> 高价值物资入口 + 少量待结算币。

宝箱房应明显强于普通搜索，但不应直接大量产出全局结算币。

---

## 7.2 宝箱待结算币

推荐公式：

```text
宝箱待结算币 = random(3, 7) + 周围雷数
最高不超过 11
```

| 周围雷数 | 待结算币范围 |
| ---: | -----: |
|    0 |    3~7 |
|    1 |    4~8 |
|    2 |    5~9 |
|    3 |   6~10 |
|    4 |   7~11 |

---

## 7.3 宝箱主掉落表

宝箱必定掉落 1 件物品。

| 品质    |  概率 |     价值区间 |
| ----- | --: | -------: |
| 低值回收物 | 15% |      3~8 |
| 普通回收物 | 45% |    10~25 |
| 稀有回收物 | 30% |   40~100 |
| 珍贵回收物 |  9% |  150~400 |
| 异常回收物 |  1% | 800~3000 |

---

## 7.4 宝箱额外掉落

| 额外掉落           |  概率 |
| -------------- | --: |
| 第 2 件低值 / 普通物品 | 25% |
| 消耗品            | 15% |
| 装备             |  3% |

---

## 7.5 高雷宝箱修正

| 条件      | 修正                            |
| ------- | ----------------------------- |
| 周围雷数 ≥3 | 珍贵 +3%，异常 +0.5%，从低值 / 普通概率中扣除 |
| 周围雷数 ≥4 | 异常额外 +0.5%，从普通概率中扣除           |

设计目的：

1. 高风险区域宝箱更有吸引力；
2. 高雷数不直接提供大量金币，而是提高高价值物概率；
3. 鼓励玩家基于扫雷信息做风险收益判断。

---

# 8. 物品价值系统

## 8.1 物品基础价值

每个物品必须拥有独立字段：

```text
baseValue
```

该字段用于：

1. 旅商出售；
2. 失败自动选择最高价值物；
3. 仓库排序；
4. 结算展示；
5. 后续出售 / 收藏 / 图鉴系统。

---

## 8.2 价值区间

| 品质    |   建议价值区间 |
| ----- | -------: |
| 低值回收物 |      3~8 |
| 普通回收物 |    10~25 |
| 稀有回收物 |   40~100 |
| 珍贵回收物 |  150~400 |
| 异常回收物 | 800~3000 |
| 唯一回收物 |    5000+ |

品质只决定掉落倾向和 UI 表现，不直接等于价格。
同品质物品之间也应存在明显价值差异。

---

## 8.3 示例物品价值

| 物品       | 类型    |   价值 |
| -------- | ----- | ---: |
| 生锈螺母     | 低值回收物 |    3 |
| 裂纹灯片     | 低值回收物 |    6 |
| 完整齿轮     | 普通回收物 |   18 |
| 旧工牌      | 稀有回收物 |   60 |
| 异常电池     | 稀有回收物 |   85 |
| 压缩核心     | 珍贵回收物 |  240 |
| 无声收音机    | 珍贵回收物 |  360 |
| 黑盒铃      | 异常回收物 | 1200 |
| 不该存在的工资条 | 唯一回收物 | 5200 |

---

## 8.4 极端高价值物规则

允许存在价值远高于常规收益的异常 / 唯一物。

但必须满足：

1. 掉率极低；
2. 失败不自动保留；
3. 旅商出售需要二次确认；
4. 成功撤离后应有强结算展示；
5. 评委模式可暂不掉落极端异常物，避免打穿展示经济。

# 9. 旅商事件

## 9.1 旅商定位

旅商的核心功能是：

> 将背包中的风险资产折价转换为安全结算币。

---

## 9.2 出售规则

玩家可选择背包内任意物品出售。

出售价格：

```text
旅商出售价格 = floor(物品 baseValue × 0.75)
最低为 1
```

| 物品价值 | 出售所得 |
| ---: | ---: |
|    3 |    2 |
|   18 |   13 |
|   60 |   45 |
|  240 |  180 |
| 1200 |  900 |

---

## 9.3 旅商所得性质

旅商出售所得建议作为安全结算币。

即：

| 情况   | 处理  |
| ---- | --- |
| 成功撤离 | 保留  |
| 失败   | 保留  |
| 后续商店 | 可使用 |

这样旅商的作用才明确：
玩家可以牺牲 25% 价值，提前锁定收益。

---

## 9.4 限制与提示

| 项目         | 规则                  |
| ---------- | ------------------- |
| 普通物品出售     | 直接确认                |
| 珍贵物品出售     | 建议确认                |
| 异常 / 唯一物出售 | 必须二次确认              |
| 装备 / 消耗品出售 | 允许，按 baseValue ×75% |
| 单个旅商事件     | 可出售多件，但事件房只触发一次     |
| 是否购买道具     | 当前版本可暂不做            |

---

# 10. 赌徒事件

## 10.1 赌徒定位

赌徒事件应当是：

> 数学期望为 0，但波动更大。

它不应成为稳定经济来源，而应制造“赌一把”的情绪。

---

## 10.2 推荐规则

消耗 20 待结算币进行一次赌博。

|  骰点 | 结果       | 净收益 |
| --: | -------- | --: |
| 1~4 | 失败，损失 20 | -20 |
|   5 | 小赢，获得 40 | +20 |
|   6 | 大赢，获得 80 | +60 |

数学期望：

```text
(-20 × 4 + 20 + 60) / 6 = 0
```

---

## 10.3 限制

| 项目          | 规则          |
| ----------- | ----------- |
| 每个赌徒事件次数    | 1 次         |
| 使用货币        | 待结算币        |
| 是否允许用全局金币下注 | 否           |
| 是否允许借贷      | 否           |
| 胜利所得        | 待结算币，不立即入全局 |

---

# 11. 祭坛事件

## 11.1 祭坛定位

祭坛事件定位为：

> 递增生命消耗换取递增收益的贪心事件。

它的核心体验是：

1. 第一次很安全；
2. 第二次开始有代价；
3. 第三次后明显影响后续探索；
4. 越继续，越接近撤离压力；
5. 玩家要决定是否继续献祭。

---

## 11.2 祭坛递增表

|    次数 | HP 消耗 | 待结算币 | 物品奖励                             |
| ----: | ----: | ---: | -------------------------------- |
| 第 1 次 |    10 |   +2 | 低值回收物                            |
| 第 2 次 |    15 |   +5 | 普通回收物                            |
| 第 3 次 |    25 |   +8 | 稀有回收物 60% / 普通回收物 40%            |
| 第 4 次 |    35 |  +10 | 珍贵回收物 30% / 稀有回收物 70%            |
| 第 5 次 |    50 |  +15 | 异常回收物 5% / 珍贵回收物 35% / 稀有回收物 60% |

---

## 11.3 支付规则

```text
只有当前 HP > 本次献祭消耗时，才允许献祭。
献祭后最低保留 1 HP。
```

祭坛不建议额外增加压力。
因为它已经通过生命消耗制造风险。

---

# 12. 消耗品与减压内容

## 12.1 消耗品表

| 消耗品 | 价值 | 效果              |
| --- | -: | --------------- |
| 压缩饼 | 15 | 恢复 15 HP        |
| 急救贴 | 25 | 恢复 25 HP        |
| 胶带卷 | 30 | 下一次受到伤害 -10     |
| 镇静糖 | 35 | 压力 -6，恢复 5 HP   |

## 12.3 减压内容限制

减压道具不能过多。

建议一局内玩家平均获得：

| 道具        | 期望数量 |
| --------- | ---: |
| 镇静糖 / 稳定剂 |  0~1 |
| 其他恢复品     |  1~2 |
| 扫描针       |  0~1 |

压力系统不能被道具完全抵消。
减压道具应是“多探索几步”的机会，而不是清空压力的手段。

# 13. 结算规则

## 13.1 成功撤离

成功撤离时：

| 内容      | 处理        |
| ------- | --------- |
| 待结算币    | 100% 转入全局 |
| 安全结算币   | 保留        |
| 背包物资    | 全部进入仓库    |
| 未使用消耗品  | 带回        |
| 装备      | 带回仓库      |
| 临时攻击力成长 | 清除        |
| 协议压力    | 清除        |
| 当前生命    | 仅用于结算展示   |

---

## 13.2 失败结算

失败时：

| 内容      | 处理         |
| ------- | ---------- |
| 待结算币    | 丢失         |
| 安全结算币   | 保留         |
| 背包物资    | 玩家选择 1 件带回 |
| 未选择物资   | 丢失         |
| 临时攻击力成长 | 清除         |
| 协议压力    | 清除         |

---

## 13.3 失败选择规则

推荐规则：

```text
失败默认可从背包中选择 1 件物资带出。
后续天赋可增加到 2 件。
```

可选择类型：

| 类型  |   是否可选 |
| --- | -----: |
| 回收物 |      是 |
| 装备  |      是 |
| 消耗品 |      是 |
| 异常物 |      是 |
| 唯一物 | 是，占用名额 |

---

## 13.4 UI 来不及时的简化方案

如果当前版本来不及制作失败选择 UI：

```text
失败时自动带出背包中 baseValue 最高的 1 件物品。
```

该方案实现简单，且能保证玩家不会因为 UI 缺失而完全失去高价值物。

# 18. 总结

当前数值方案的核心是：

> 收紧全局结算币，放大背包物资价值，让撤离和旅商成为资产兑现节点。

具体表现为：

1. 普通搜索不再大量给钱；
2. 宝箱主要给物资，而不是直接给全局金币；
3. 旅商通过 75% 折价锁定安全收益；
4. 怪物主要提供攻击成长，而不是经济收益；
5. 祭坛提供生命换物资的递增贪心；
6. 赌徒提供零期望高波动；
7. 失败只能带出有限物资；
8. 成功撤离才能完整兑现收益。

这套结构能让玩家的核心决策变成：

> 我现在背包里的东西值不值得继续冒险？
> 是卖给旅商锁收益，还是继续找撤离点？
> 是打怪变强，还是避免压力上升？
> 是继续献祭，还是保留生命撤离？

这更符合当前“扫雷情报驱动的封锁区撤离 Demo”的核心体验。
