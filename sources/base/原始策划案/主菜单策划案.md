# 《灰尾回收 / 五四三二一》主菜单界面策划案

## 规则层与界面结构草案 v0.1

> 文档定位：主菜单界面结构、入口分层、交互边界、公告栏、快捷入口、角色展示、红点提示与图层分层的策划案
> 适用范围：游戏启动后的基地主界面 / 主菜单界面
> 当前原则：主菜单保持简洁，只承担入口、氛围、轻量提示与跳转职责；不承担资源管理、任务管理、出勤配置、仓库整理和长期成长操作
> 核心目标：让玩家进入游戏后清楚知道“从哪里出发、从哪里查看长期系统、从哪里设置、如何退出”，同时保留基地氛围与少量可自定义快捷入口

---

## 0. 主菜单定位

主菜单是玩家进入游戏后的基地入口页。

主菜单负责：

1. 展示基地氛围；
2. 展示当前角色；
3. 提供固定主入口；
4. 提供少量可自定义快捷跳转；
5. 显示轻量公告或世界观短讯；
6. 提供外观配置快捷入口；
7. 提供设置和退出游戏入口；
8. 显示必要但克制的红点 / 角标提示。

主菜单不负责：

1. 展示金币、黑币、抽奖券等资源数值；
2. 展示任务进度；
3. 展示资历经验条；
4. 展示仓库容量；
5. 处理出勤配置；
6. 处理完整仓库；
7. 处理完整图鉴；
8. 处理抽奖主界面；
9. 处理研究系统；
10. 展示“继续上次配置”；
11. 直接开始探索或继续探索。

主菜单的定位是：

> 基地门厅 / 中控入口，而不是局外系统总面板。

## 1. 主菜单固定大入口

主菜单固定显示四个大入口：

```text
出发探索
长期系统
设置
退出游戏
```

四个大入口不随玩家进度、存档状态、任务状态或系统解锁变化而增减。

### 1.1 出发探索

“出发探索”按钮始终显示为“出发探索”。

即使当前存在进行中探索，主菜单按钮也不改名为“继续探索”。

“开始探索 / 继续探索”的切换发生在出发探索页面内部，而不是主菜单中。

出发探索入口负责进入：

1. 地图选择；
2. 仓库；
3. 申领；
4. 出勤配置；
5. 作业许可；
6. 开始探索 / 继续探索二级操作。

### 1.2 长期系统

长期系统入口负责进入：

1. 任务；
2. 图鉴；
3. 成就；
4. 回收资历；
5. 研究；
6. 抽奖 / 收藏 / 外观相关长期内容。

抽奖系统不作为主菜单独立大入口，而是归入长期系统中，与其他长期系统内容并列。

### 1.3 设置

设置入口负责进入：

1. 画面设置；
2. 音频设置；
3. 操作设置；
4. 语言设置；
5. 辅助功能；
6. 自定义快捷入口；
7. 主菜单动效设置；
8. 红点提示设置；
9. 公告栏显示设置；
10. 存档 / 其他系统设置。

### 1.4 退出游戏

退出游戏作为第四个固定主按钮。

点击后需要二次确认。

若当前存在进行中探索，退出确认中应说明：

1. 当前存在进行中探索；
2. 退出游戏不等于放弃探索；
3. 下次进入游戏后可从出发探索页继续当前探索；
4. 若要放弃当前探索，需要进入出发探索页进行放弃操作。

## 2. “开始探索 / 继续探索”的归属

“开始探索 / 继续探索”不出现在主菜单。

该操作位于：

```text
出发探索页面 → 右侧出勤准备区域 / 主操作按钮
```

### 2.1 无进行中探索时

出发探索页主操作按钮显示：

```text
开始探索
```

玩家完成地图、装备、遗物、消耗品、保险、作业许可等出勤配置后，可点击开始新局。

### 2.2 有进行中探索时

出发探索页主操作按钮显示：

```text
继续探索
```

并显示进行中探索摘要，例如：

1. 当前地图；
2. 当前生命；
3. 当前背包状态；
4. 当前探索进度；
5. 当前协议状态；
6. 当前是否处于安全状态。

如玩家需要开始新探索，必须先在出发探索页中选择“放弃当前探索”，并经过强确认。

### 2.3 主菜单不显示“继续上次配置”

“继续上次配置”不放在主菜单。

该功能应归入：

```text
出发探索 → 出勤配置
```

可作为：

1. 套用上次配置；
2. 保存当前配置；
3. 读取配置预设。

## 3. 主菜单资源显示规则

主菜单不常驻显示资源数值。

不显示：

1. 金币；
2. 黑币；
3. 抽奖券；
4. 特殊长期资源；
5. 任务进度；
6. 资历经验；
7. 仓库容量；
8. 背包容量；
9. 局内压力；
10. 当前探索详细状态。

资源信息只在对应功能页中显示。

例如：

| 信息   | 显示位置                |
| ---- | ------------------- |
| 金币   | 申领、抽奖、研究、商店等需要消费的页面 |
| 黑币   | 局内界面与结算界面           |
| 抽奖券  | 抽奖 / 收藏界面           |
| 任务进度 | 长期系统 → 任务           |
| 资历经验 | 长期系统 → 回收资历         |
| 仓库内容 | 出发探索 → 仓库           |
| 背包容量 | 出发探索 → 出勤配置 / 局内界面  |

主菜单只允许通过红点 / 角标表达“有新内容或待处理事项”，不展示具体资源数量。

## 4. 公告栏规则

主菜单保留轻量公告栏。

公告栏用于：

1. 世界观补充；
2. 公司公告；
3. 更新内容说明；
4. 补给到货提示；
5. 委托刷新提示；
6. 研究完成提示；
7. 剧情广播；
8. 系统短讯。

公告栏不用于：

1. 展示完整任务列表；
2. 展示复杂活动入口；
3. 展示资源数值；
4. 展示抽奖广告式内容；
5. 展示强制日常压力；
6. 占用主界面大面积空间。

公告栏显示建议：

1. 面积较小；
2. 最多显示 2–3 条短消息；
3. 点击后进入对应详情或对应系统；
4. 可在设置中隐藏或弱化；
5. 文案应优先清楚，可带少量公司式黑色幽默。

## 5. 自定义快捷跳转

主菜单可显示 2–3 个快捷跳转按钮。

快捷跳转不由系统强制固定，而由玩家在设置中自定义。

### 5.1 数量限制

快捷跳转数量限制为：

```text
2–3 个
```

不允许无限增加，避免主菜单按钮堆叠。

### 5.2 可选目标

可选快捷目标包括：

1. 仓库；
2. 图鉴；
3. 任务；
4. 研究；
5. 抽奖 / 收藏；
6. 外观；
7. 出勤配置；
8. 地图；
9. 申领；
10. 作业许可；
11. 最近使用页面。

### 5.3 默认快捷入口

首次进入游戏时可提供默认快捷入口。

推荐默认：

```text
仓库
图鉴
```

或：

```text
仓库
任务
```

玩家可在设置中修改。

### 5.4 快捷入口边界

快捷入口只是跳转，不承担详细功能。

快捷入口不显示：

1. 具体资源数量；
2. 任务进度；
3. 仓库容量；
4. 完整面板内容；
5. 出勤配置细节。

---

## 6. 角色展示与外观入口

主菜单保留角色展示区域。

角色展示用于：

1. 展示当前角色；
2. 展示当前外观；
3. 展示基地氛围；
4. 提供轻量个性化入口。

### 6.1 外观入口

角色脚边可出现一个小型外观入口按钮。

按钮建议命名为：

```text
外观
```

或：

```text
穿搭
```

不建议命名为“设置”，避免和主菜单大入口“设置”混淆。

### 6.2 外观界面归属

外观配置本体归入：

```text
长期系统 → 收藏 / 外观
```

主菜单角色脚边按钮只是快捷跳转。

### 6.3 外观规则

外观系统不应提供局内数值收益。

外观不进入：

1. 出勤效果总览；
2. 战斗数值；
3. 背包容量；
4. 黑币收益；
5. 主线推进；
6. Boss 挑战条件。

---

## 7. 红点 / 角标规则

主菜单允许显示少量红点 / 角标。

红点用于提示：

1. 有新内容；
2. 有未读信息；
3. 有可领取奖励；
4. 研究完成；
5. 图鉴新增；
6. 仓库新增；
7. 委托更新；
8. 外观新获得。

红点不用于：

1. 诱导抽奖；
2. 强制日常；
3. 资源够用提醒；
4. 商店刷新压力；
5. 每个子系统都挂提示；
6. 制造无意义点击负担。

### 7.1 红点显示原则

1. 克制；
2. 可理解；
3. 可关闭或弱化；
4. 不显示复杂数值；
5. 不遮挡主入口；
6. 不影响主界面简洁性。

### 7.2 设置项

设置中应提供：

1. 弱化红点提示；
2. 关闭非关键红点；
3. 保留关键系统提示；
4. 清除已读提示。

---

## 8. 结算后的主界面关系

局内结束后，不直接跳回主菜单作为默认结果。

推荐流程：

```text
局内结束
↓
结算界面
↓
仓库新增 / 带回物资确认页
↓
玩家确认物资
↓
返回主菜单 / 出发探索 / 长期系统
```

### 8.1 仓库新增页

仓库新增页用于展示：

1. 本局带回物品；
2. 本局抢救物品；
3. 新增装备；
4. 新增遗物；
5. 新增藏品；
6. 新增唯一外观；
7. 新增图鉴条目；
8. 黑币转金币结果；
9. 消耗品清空提示；
10. Buff / Debuff 持续变化。

### 8.2 仓库新增页操作

仓库新增页可提供：

1. 整理仓库；
2. 查看图鉴新增；
3. 继续出发；
4. 返回主菜单。

主菜单本身不承担结算后物资展示。

## 9. 主菜单图层分层

主菜单必须进行图层分层。

所有可能产生动效、交互、提示、弹窗、过渡的内容都应分层管理，避免后续 UI 混乱。

### 9.1 背景静态层

内容：

1. 基地背景；
2. 墙面；
3. 地板；
4. 大型固定道具；
5. 远景；
6. 固定基地装饰。

规则：

1. 不承载交互；
2. 不承载按钮；
3. 尽量不频繁刷新；
4. 作为底层基础画面。

---

### 9.2 背景动效层

内容：

1. 灯光闪烁；
2. 屏幕扫描线；
3. 机器运转；
4. 窗外光影；
5. 灰尘粒子；
6. 基地轻动效；
7. 环境小动画。

规则：

1. 与背景静态层分离；
2. 不与主 UI 混在一起；
3. 可被设置中的“降低主菜单动效”关闭或减弱；
4. 不应影响主要按钮识别。

---

### 9.3 角色展示层

内容：

1. 当前角色；
2. 角色待机动画；
3. 当前外观展示；
4. 角色阴影；
5. 角色装饰表现。

规则：

1. 与背景分离；
2. 外观变化只影响该层或相关角色资源；
3. 角色待机动画不影响主 UI；
4. 角色脚边外观按钮不直接并入角色层，应放入交互热点层。

---

### 9.4 前景装饰层

内容：

1. 桌子；
2. 柜子；
3. 前景设备；
4. 遮挡物；
5. 公告板实体；
6. 基地小物件。

规则：

1. 用于增强空间感；
2. 不承载复杂 UI；
3. 若有点击交互，应在交互热点层另设区域。

---

### 9.5 交互热点层

内容：

1. 角色脚边外观按钮；
2. 公告板点击区域；
3. 可点击装饰物；
4. 基地小按钮；
5. 小型快捷交互区域。

规则：

1. 只承载点击区域；
2. 与视觉资源分离；
3. 点击后跳转或打开小面板；
4. 不直接塞入复杂内容。

---

### 9.6 主按钮 UI 层

内容：

1. 出发探索；
2. 长期系统；
3. 设置；
4. 退出游戏。

规则：

1. 四个主按钮固定；
2. 位置稳定；
3. 不随进度增减；
4. 可有 hover / focus / selected 状态；
5. 不显示资源数值；
6. 不显示任务进度。

---

### 9.7 公告栏 UI 层

内容：

1. 公司公告；
2. 世界观短讯；
3. 更新内容；
4. 补给提示；
5. 研究提示；
6. 委托刷新提示。

规则：

1. 面积小；
2. 信息短；
3. 不展开完整系统；
4. 可点击进入详情；
5. 可在设置中隐藏或弱化。

---

### 9.8 自定义快捷入口层

内容：

1. 玩家自定义快捷入口 1；
2. 玩家自定义快捷入口 2；
3. 玩家自定义快捷入口 3。

规则：

1. 数量限制 2–3；
2. 目标由设置配置；
3. 不显示复杂状态；
4. 可显示轻量角标；
5. 不与主按钮混淆。

---

### 9.9 红点 / 角标层

内容：

1. 新内容提示；
2. 未读提示；
3. 可领取提示；
4. 仓库新增提示；
5. 图鉴新增提示；
6. 研究完成提示。

规则：

1. 独立于按钮图形；
2. 可统一管理；
3. 可被设置弱化；
4. 不显示具体资源数值；
5. 不用于诱导抽奖。

---

### 9.10 弹窗 / 确认层

内容：

1. 退出游戏确认；
2. 公告详情；
3. 错误提示；
4. 放弃探索提示的跳转确认；
5. 其他强提示弹窗。

规则：

1. 位于主界面最上层；
2. 出现时阻挡底层按钮输入；
3. 可令背景轻微变暗；
4. 关闭后返回原状态；
5. 不与过渡遮罩层混用。

---

### 9.11 过渡 / 遮罩层

内容：

1. 进入出发探索过渡；
2. 进入长期系统过渡；
3. 退出游戏淡出；
4. 页面加载；
5. 恢复探索加载；
6. 场景切换遮罩。

规则：

1. 用于页面跳转；
2. 不承载长期 UI；
3. 可被“降低动效”设置影响；
4. 不与弹窗层混用。

---

## 10. 设置中与主菜单相关的选项

设置中应预留以下主菜单相关选项：

1. 自定义快捷入口；
2. 降低主菜单动效；
3. 弱化红点提示；
4. 隐藏或弱化公告栏；
5. 清除已读提示；
6. 外观按钮显示开关，如有需要；
7. 主菜单动效强度；
8. 过渡动画强度。

### 10.1 自定义快捷入口

玩家可选择 2–3 个快捷入口目标。

可选目标：

1. 仓库；
2. 图鉴；
3. 任务；
4. 研究；
5. 抽奖 / 收藏；
6. 外观；
7. 出勤配置；
8. 地图；
9. 申领；
10. 作业许可；
11. 最近使用页面。

## 11. 主菜单不应承担的功能

为避免主菜单过载，明确禁止将以下内容放入主菜单常驻显示：

1. 金币数值；
2. 黑币数值；
3. 抽奖券数值；
4. 任务进度条；
5. 资历经验条；
6. 仓库容量；
7. 背包容量；
8. 出勤配置详情；
9. 继续上次配置；
10. 完整仓库；
11. 完整图鉴；
12. 抽奖大入口；
13. 外观主面板；
14. 研究列表；
15. 商店列表；
16. 保险 / 托运详情；
17. Boss 情报详情；
18. 每日任务列表；
19. 复杂活动入口。

## 12. 主菜单最低验收标准

主菜单完成后，应满足：

1. 显示基地背景；
2. 显示当前角色；
3. 显示四个固定主按钮；
4. 出发探索按钮不随进行中探索状态改名；
5. 长期系统按钮固定；
6. 设置按钮固定；
7. 退出游戏按钮固定；
8. 退出游戏有确认；
9. 不显示金币等资源数值；
10. 不显示任务进度；
11. 不显示继续上次配置；
12. 支持 2–3 个自定义快捷入口；
13. 快捷入口可在设置中配置；
14. 保留轻量公告栏；
15. 公告栏不占大篇幅；
16. 支持少量红点 / 角标；
17. 红点可被弱化；
18. 支持角色脚边外观快捷按钮；
19. 外观配置不在主菜单展开；
20. 背景动效与 UI 按钮分层；
21. 交互热点与视觉图层分离；
22. 弹窗与过渡层分离；

24. 主菜单整体保持简洁。

## 13. 待确认项

后续仍需确认：

1. 快捷入口默认目标是“仓库 + 图鉴”还是“仓库 + 任务”；
2. 快捷入口最大数量是 2 个还是 3 个；
3. 公告栏默认是否开启；
4. 公告栏是否可完全隐藏；
5. 红点弱化后具体表现；
6. 外观按钮正式命名；
7. 外观按钮具体放在角色脚边哪个位置；
8. 主按钮具体排序是否固定为：出发探索、长期系统、设置、退出游戏；
9. 退出游戏确认文案；
10. 有进行中探索时，出发探索页如何显示继续探索；
11. 结算后仓库新增页的返回路径；
12. 主菜单动效默认强度；
13. 减少动效模式下保留哪些动画；
14. 公告栏点击后的详情页面归属。

## 14. 总结

主菜单最终定位为：

> 一个简洁的基地入口页。

它只承担：

1. 氛围展示；
2. 角色展示；
3. 四个固定大入口；
4. 轻量公告；
5. 少量自定义快捷跳转；
6. 轻量红点提示；
7. 外观快捷入口。

它不承担：

1. 资源总览；
2. 任务追踪；
3. 复杂仓库；
4. 出勤配置；
5. 抽奖主入口；
6. 研究处理；
7. 长期成长细节。

主菜单应把复杂系统留给“出发探索”和“长期系统”，自身保持稳定、清晰、简洁，并通过图层分离保证后续动效、交互和提示能够独立维护。
