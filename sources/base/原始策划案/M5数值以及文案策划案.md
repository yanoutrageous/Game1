# M5 数值以及文案策划案

## 0. 文档定位

本文档用于 M5 阶段执行。

M5 阶段目标不是重新定义玩法规则，而是把以下两份早期策划案中可继续使用的数值、文案、术语、物品命名、事件表达和 UI 提示，经过最新策划案裁决后，整理为可落地素材：

```text
D:\AGAME1\Base Docs\文案策划案v0.3.txt
D:\AGAME1\Base Docs\数值策划案.txt
```

这两份文档时间早于后续系统策划案，且部分内容来自 Lua 原型，因此不能作为规则权威。

M5 执行时必须遵守：

```text
1. 规则以最新策划案为准。
2. 尤其以《最小物品包与掉落闭环内容策划案 v0.2》为物品、掉落、背包、结算、唯一物、消耗品、旅商、安全收益的最高依据。
3. 早期文案 / 数值只作为素材库。
4. 凡是冲突内容必须改写后再接入。
5. 不允许直接接入“失败默认带 1 件”“结算币等于全局金币”“唯一物可普通掉落”等旧 Lua 原型规则。
6. 每个接入内容必须能被除这两份早期案之外的策划案支撑。
```

## 6. 物品显示名与描述

### 6.1 作业装备 6 件

M5 推荐使用这些策划名作为显示名：

| 显示名 | 类型 | 效果方向 | 描述 |
|---|---|---|---|
| 旧背心 | 作业装备 | 提高生命 / 减伤 | 前任员工留下的，至少背心还在。后勤部表示清洗过，程度有限。 |
| 开刃器 | 作业装备 | 提高战斗力 | 让你的工具看起来更像武器。公司称这仍属于“非攻击性作业辅助”。 |
| 回收袋 | 作业装备 | 提高负重 | 比标准背包多两个口袋。后勤部提醒：多装不代表能安全带回。 |
| 护目镜 | 作业装备 | 强化扫描 | 镜片有裂纹，但能过滤一部分错误读数。也可能只是让错误看起来更专业。 |
| 信号针 | 作业装备 | 撤离提示 | 指针总会发抖，但至少知道大概该往哪里跑。 |
| 绝缘套 | 作业装备 | 降低雷险伤害 | 对雷险没有完全作用，但心理上很有作用。 |

执行要求：

```text
可保留现有工程 ID；
改显示名和描述；
局内获得装备必须标记为未登记装备；
局内获得装备不立即生效；
出发前配置的装备才生效。
```

### 6.2 作业消耗品 6 件

| 显示名 | 类型 | 效果方向 | 描述 |
|---|---|---|---|
| 压缩饼 | 作业消耗品 | 恢复少量生命 | 味道像纸箱。公司称其为能量补给。 |
| 急救贴 | 作业消耗品 | 恢复中量生命 | 对小伤有效。对大伤有安慰效果。 |
| 胶带卷 | 作业消耗品 | 下一次受伤减免 | 修不了设备，但能让设备暂时停止表达意见。 |
| 扫描针 | 作业消耗品 | 扫描相邻未知格 | 能探出一点雷险反应。探不到的部分，后勤称为“员工判断空间”。 |
| 镇静糖 | 作业消耗品 | 小幅减压 + 小恢复 | 含糖量很高。心理作用也很高。 |
| 稳定剂 | 作业消耗品 | 强减压 | 稀少，不应允许玩家持续清空压力。 |

执行要求：

```text

未使用且成功撤离可入仓；
```

## 7. 可接入的数值方向

### 7.1 玩家基础数值

可作为默认占位：

```text
玩家最大生命：100
初始生命：100
初始攻击力：10
雷险伤害：30
雷险重复触发：否
普通搜索攻击力提升：0
击败怪物攻击力提升：+1
单局击杀攻击力成长上限：+5
```

交叉依据：

```text
M3 允许协议 / 雷险 / 消耗品接口；
战斗房案支持怪物战斗成长；
数值可作为可调占位，不应写死到不可调逻辑。
```

### 7.2 协议压力数值

可作为默认占位：

```text
探索未知格：+2 压力
开宝箱：+0 压力
击败怪物：+5 压力
踩雷：+10 压力
使用减压道具：-6 / -10
压力范围：0~100
协议阈值：0~19 = 5，20~39 = 4，40~59 = 3，60~79 = 2，80~100 = 1
```

必须保留规则：

```text
回传已探索区域不加压力；
查看地图不加压力；
查看背包不加压力；
拾取 / 丢弃不加压力；
扫描但不探索不加压力；
协议惩罚只绑定继续探索未知区域。
```

### 7.3 普通搜索

可采用方向：

```text
普通搜索 = 小额反馈 + 低概率低级物资 + 少量本局黑币。
普通搜索不提升攻击力。
普通搜索不产出 5-7 级藏品。
普通搜索不产出唯一物。
```

可用占位数值：

```text
普通搜索本局黑币 = random(0, 2) + floor(周围雷险 / 2)
最高不超过 4
```

掉落方向：

```text
普通搜索主要 1-3 级藏品；
高雷搜索极低概率 4 级藏品；
可低概率掉落压缩饼、急救贴、胶带卷；
不掉 5-7 级。
```

### 7.4 宝箱

可采用方向：

```text
宝箱 = 高价值物资入口 + 少量本局黑币。
宝箱必定有主奖励。
宝箱不产出唯一物。
宝箱不直接大量产出长期金币。
```

可用占位数值：

```text
宝箱本局黑币 = random(3, 7) + 周围雷险
最高不超过 11
```

掉落方向：

```text
2-6 级藏品
作业消耗品
未登记装备
少量本局黑币
```

高雷宝箱：

```text
提高 4-6 级藏品概率；
不显著提高本局黑币。
```

### 7.5 怪物

可采用方向：

```text
怪物主奖励 = 战斗成长。
怪物不是主要经济来源。
普通怪物不稳定大量产出金币。
```

可用占位数值：

```text
击败怪物：+1 攻击力
击杀攻击力成长上限：+5
击败怪物压力：+5
击败怪物本局黑币：0~3
怪物掉物概率：15%
高强度怪掉物概率：25%
```

注意：

```text
具体怪物 HP / 攻击 / 冷却可作为 placeholder；
不应在 M5 扩成完整战斗房与怪物系统；
下注怪物若工程基础不足，做 disabled + reason。
```

### 7.6 旅商

可直接采用：

```text
旅商出售价格 = floor(baseValue × 0.75)
最低为 1
```

收益性质：

```text
旅商出售所得 = 安全收益。
成功撤离后写入长期金币。
失败后也写入长期金币。
```

提示文案：

```text
少赚一点，但已经安全。
```

必须支持：

```text
出售背包物品；
高价值物品二次确认；
唯一物不能普通出售；
出售后物品从背包移除；
结果写入安全收益，而不是直接长期金币。
```

M5 P1 可加入：

```text
购买急救服务；
购买雷险信息。
```

如果不做完整购买系统，必须显示 disabled reason。

### 7.7 旧区概率装置 / 骰子

可采用方向：

```text
高波动本局黑币事件。
只使用本局黑币。
不能用长期金币下注。
不能借贷。
胜利所得仍是本局黑币。
```

可用占位规则：

```text
消耗 20 本局黑币；
1~4：失败，损失 20；
5：小赢，净赚 20；
6：大赢，净赚 60；
数学期望约 0。
```

必须避免：

```text
直接给长期金币；
借贷；
无限重复刷。
```

### 7.8 临时祭坛

可采用方向：

```text
生命换递增收益。
不直接产出唯一物。
不额外增加压力，除非高难 modifier。
献祭后最低保留 1 HP。
```

可用占位阶梯：

| 次数 | HP 消耗 | 奖励方向 |
|---|---:|---|
| 第 1 次 | 10 | 本局黑币 + 1-2 级藏品 |
| 第 2 次 | 15 | 本局黑币 + 2-3 级藏品 |
| 第 3 次 | 25 | 本局黑币 + 3-4 级藏品 |
| 第 4 次 | 35 | 4-5 级藏品 |
| 第 5 次 | 50 | 5-6 级藏品 |

必须避免：

```text
产出唯一物；
把 HP 降到 0；
绕过 GroundLoot / 背包。
```

## 8. 结算文案

### 8.1 撤离确认

```text
撤离信标已接入。
结束本次作业并结算当前收益。
继续探索可能获得更多收益，也可能失去已有收益。
```

按钮：

```text
结束作业
再捡一点
```

### 8.2 成功标题

```text
作业完成
成功撤离
```

成功短句：

```text
你带回了物资，也带回了自己。
黑币已结算。
后勤仓库已更新。
```

必须展示：

```text
本局黑币 → 长期金币
安全收益 → 长期金币
背包物品 → 后勤仓库
未使用消耗品 → 后勤仓库
未登记装备 → 后勤仓库
GroundLoot 未拾取 → 丢失
```

### 8.3 失败标题

```text
信号中断
撤离失败
```

失败短句：

```text
公司正在努力把这解释为流程问题。
作业失败。部分收益已按最低条款抢救。
后勤部找回了一点东西。好消息：里面可能有你的。
```

必须展示：

```text
本局黑币：已丢失
安全收益：已保留
背包物资：按抢救负重处理
抢救物：进入后勤仓库
未抢救物：已丢失
GroundLoot 未拾取：已丢失
```

禁止旧文案：

```text
失败默认带 1 件。
未使用消耗品默认清空。
结算币属于安全收益，失败后仍会入账。
```

应改为：

```text
失败抢救按抢救负重 / 抢救容量处理。
未使用作业消耗品可进入抢救候选。
安全收益失败后仍会写入长期金币。
本局黑币失败后丢失。
```

### 8.4 放弃 / 中止

可用标题：

```text
作业中止
```

必须说明：

```text
不算成功撤离；
不等同死亡失败；
本局黑币默认不转化；
背包物默认不带回；
安全收益是否保留按当前规则显示，如未裁决则标记 pending / 待定；
Debug 路径需明确标记。
```

## 12. 最终裁决

可接入 M5 的内容主要是：

```text
文案 v0.3：世界观、术语、UI 文案、物品名、事件文案、结算文案、公司口吻。
数值案：收益方向、占位参数、旅商倍率、压力变化、搜索 / 宝箱 / 怪物 / 祭坛 / 赌徒的数值初稿。
```

不可直接接入的是：

```text

结算币混同全局资产；
唯一物普通掉落；
旧 Lua Demo 中来不及实现的降级规则；
与 M3 v0.2、RunFlow、Room/Encounter、Rule/Effect/Pool、Settlement 冲突的规则。
```

执行框应把本文档作为 M5 content/text/balance source filter，所有落地内容必须经过最新策划案约束后再实现。
