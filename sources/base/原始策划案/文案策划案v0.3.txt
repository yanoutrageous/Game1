# 1. 核心文案方向

## 1.1 核心气质

本项目的文案气质为：

> 可爱动物外壳，糟糕工作现场。
> 玩家不是英雄，而是进入封锁区执行危险工单的临时回收员。
> 公司不邪恶到夸张，但足够冷漠、抠门、流程化，并善于规避责任。

## 1.2 文案比例

建议整体文案比例：

* 70%：功能清楚；
* 20%：公司术语；
* 10%：黑色幽默。

核心规则和教程文案必须优先清楚。
黑色幽默主要放在广播、失败、结算、物品描述、旅商对话、按钮文案中。
不要让段子遮挡玩法理解。

# 4. 世界观设定

## 4.1 一句话世界观

在被封锁的旧设施中，动物回收员们接下危险工单，依靠区域扫描图判断雷险，搜刮物资，并在撤离协议恶化前尽量完整地回来。

## 4.2 一句话玩法介绍

你是一名浣熊临时回收员，在扫雷规则构成的封锁区中探索、搜刮、避险、清理异常体，并带着收益撤离。

## 4.3 黑色幽默版一句话

这是一份看数字、捡东西、躲危险、找出口的临时工；公司承诺结算报酬，但不承诺结算你。

# 5. 世界基本设定

## 5.1 世界概况

这是一个拟人动物社会。

城市表面仍然有秩序：工厂开工，商铺营业，调度台准时播报，后勤部按表格结算。

但在城市边缘、旧矿道深处、废弃仓储带和地下运输线以下，有许多已经从公共地图上消失的区域。

它们被统一称为：

# 封锁区

封锁区的来历各不相同。
有些是事故后的旧工厂，有些是废弃矿井，有些是沉降后被放弃的地下街区，也有些只是公司档案里写得很含糊的“历史遗留设施”。

这些地方通常不适合居住，不适合调查，也不适合正式员工进入。

但很适合回收。

至少，回收公司是这么说的。

---

## 5.2 封锁区内容

封锁区中可能存在：

* 旧时代遗留的机关；
* 不稳定的雷险节点；
* 失控的维修设备；
* 异常体；
* 废弃物资箱；
* 仍可转卖的异常回收物；
* 私下营业的旅商；
* 不明来源的事件装置；
* 可接入的撤离信标。

当前 Demo 展示的是一个标准封锁区工单。
未来扩展中的蜂窝地图、多层地牢、特殊规则地图，都可以解释为不同类型的封锁区。

# 6. 玩家身份

## 6.1 玩家职业

玩家是一名：

# 浣熊临时回收员

他不是英雄。
不是正规调查员。
不是军人。
不是被选中的救世主。

他只是背着旧背包、戴着公司头盔、拿着区域扫描终端，进入封锁区执行短程回收任务的小动物打工人。

## 6.2 玩家任务

玩家的任务是：

1. 进入封锁区；
2. 读取区域扫描图；
3. 判断雷险位置；
4. 搜刮异常回收物；
5. 避开或清理异常体；
6. 找到撤离信标；
7. 带着物资回来；
8. 尽量不要变成物资。

灰尾回收公司是一家承接封锁区资产清理业务的外包公司。

# 9. 五四三二一撤离协议

## 9.1 定位

“五四三二一”不是整个世界观的唯一核心，也不默认作为最终游戏名。

它在游戏内是：

# 五四三二一撤离协议

这是封锁区回收行业中常用的返程广播标准。

协议数字从 5 下降到 1。
数字越低，代表区域读数越糟，调度台越不建议继续深入。

协议不直接替玩家做决定。
它只负责提醒：

> 继续深入可能还有收益，也可能让你成为下一批回收目标。

## 9.2 协议文案表

| 协议等级 | 阶段名  | HUD 短句        | 降级广播                                      |
| ---- | ---- | ------------- | ----------------------------------------- |
| 5    | 正常作业 | 区域稳定，允许回收。    | 调度台 A-7：协议 5。区域读数稳定，继续作业。                 |
| 4    | 轻度警戒 | 读数上升。保持判断。    | 调度台 A-7：协议 4。异常读数上升，请保持职业判断。              |
| 3    | 风险作业 | 高收益区，高事故区。    | 调度台 A-7：协议 3。继续深入将提高收益，也提高事故概率。本条为非强制性建议。 |
| 2    | 返程建议 | 信标仍在服务中，暂时。   | 调度台 A-7：协议 2。建议返程。建议不是命令，但也不是玩笑。          |
| 1    | 最终建议 | 撤离是建议，不撤离是选择。 | 调度台 A-7：协议 1。撤离是建议。不撤离是自主选择。相关条款已说明。      |

## 9.3 协议短句池

* 协议下降。
* 封锁压力上升。
* 区域读数恶化。
* 撤离建议已更新。
* 协议下降一级。这不是命令，这是风险告知。
* 建议返程。建议不是命令，但也不是玩笑。
* 公司已尽到提醒义务。剩余义务由员工自行承担。
* 你已进入高收益区。高事故区。这两个区域通常是同一个。
* 撤离信标仍在服务中。它不会等你，只是暂时还没走。

# 10. 异常体设定

## 10.1 总定义

异常体是封锁区内被异常影响后仍在活动的对象。

它们不统一等同于怪物，也不全是生物。
异常体可以是旧设备、异变生物、失控系统，也可以是无法归类的异常现象。

## 10.2 三分类

| 分类    | 说明              | 当前优先级         | 示例                                   |
| ----- | --------------- | ------------- | ------------------------------------ |
| 旧设施残留 | 被异常能量激活的非生命系统   | 当前 Demo P0 主力 | 滞留工偶、空壳巡工、失控搬运机、清道机群、声控蜂群、头灯哨卫、管道清理机 |
| 异变生物  | 被封锁区环境改变的生物     | P2 扩展         | 废铁鼠群、盲声蝠群、管道咬合兽                      |
| 异常现象  | 无法归类为设备或生物的能量残留 | P2 扩展         | 广播残响、回收残影、断线执行体                      |

## 10.3 当前 Demo 使用原则

当前 Demo 怪物房敌人优先使用“旧设施残留”类别，以保证风格统一。
未来扩展时，可逐步加入异变生物和异常现象。

# 13. 开场教程文案

## 13.1 极短版

你是进入封锁区的浣熊回收员。
数字表示周围 8 个区域中的雷险数量。
搜刮回收物，避开危险，在撤离协议恶化前找到信标。

## 13.2 标准版

欢迎入职灰尾回收。

你将进入封锁区，回收仍有价值的物资。
区域扫描图会显示周围 8 个区域中的雷险数量。
斜向区域也会计入数字，但不能直接移动进入。
异常体、物资箱、旅商和撤离信标不计入该数字。

找到撤离信标后，你可以结束本次作业。
成功撤离会完整结算收益。

请注意：
公司建议你带回物资。
更建议你带回自己。

## 13.3 分步教程

### 教程 1：身份

你是封锁区临时回收员。
进入区域，搜刮物资，找到撤离信标。

### 教程 2：数字

数字表示周围 8 个区域中的雷险数量。
斜向区域也会计入。
异常体、物资、事件和撤离点不计入数字。

### 教程 3：移动

你只能通过上下左右出口进入相邻区域。
斜向区域只参与雷险计算，不能直接通行。

### 教程 4：雷险

雷险区会触发陷阱并造成伤害。
已触发的雷险会被标记，再次经过不会重复触发。

### 教程 5：异常体

异常体区域可以直接穿过。
躲开攻击即可离开。
击败异常体可获得奖励并清理该区域。

### 教程 6：物资

物资箱中可能有结算币、作业消耗品、临时状态或异常回收物。
异常回收物通常不会在局内直接生效，但可以出售或收藏。
能带走多少，取决于你有没有活着撤离。

局内发现的装备类物品不会立即生效。
成功撤离后，它们将作为未登记装备入库，下次出勤才能配置。

### 教程 7：撤离

到达撤离信标后可选择撤离。
成功撤离会完整结算本次收益。

### 教程 8：协议

探索未知区域会提高封锁压力。
五四三二一撤离协议下降时，建议考虑返程。
公司不会替你做决定。合同会。

# 17. 资源与物品分类文案

## 17.1 资源与物品总分类

| 类型    | 定位       | 是否局内生效 |  是否可带回 | 说明               |
| ----- | -------- | -----: | -----: | ---------------- |
| 结算币   | 安全收益     |      否 |      是 | 直接计入账户，失败后通常保留   |
| 作业装备  | 出勤配置     |      是 |      是 | 从局外带入，局内持续生效     |
| 作业消耗品 | 一次性物资    |      是 | 未使用可带回 | 使用后产生局内即时或临时效果   |

---

## 17.2 作业装备定义

作业装备是出发前从后勤申领并带入封锁区的配置。

作业装备在局内持续产生效果。
例如提高生命、战斗力、负重、扫描能力、雷险抗性或撤离感知能力。

局内搜刮到的装备类物品不会立即生效。
它们会被视为异常回收物或未登记装备，成功撤离后进入后勤仓库，之后才能作为出勤配置处理。

### 简短说明

> 作业装备：带进去才生效。捡到的不算装备，先算回收物。

---

## 17.3 作业消耗品定义

作业消耗品是在局内使用的一次性物资。

使用后会产生即时或临时效果。
例如恢复生命、降低伤害、扫描雷险、短时间提高战斗力、减少封锁压力等。

未使用的作业消耗品在成功撤离后可带回后勤仓库。
已使用的作业消耗品不会返还。

### 简短说明

> 作业消耗品：用了才有效，用完就没有。后勤称这叫“合理损耗”。

---

## 17.4 异常回收物定义

异常回收物是在封锁区中发现的可带回物品。

它们通常不产生局内效果。
它们的价值在于出售、收藏、解锁图鉴、补充世界观，或作为后续事件 / 仓库 / 交易系统的资源。

异常回收物可以卖给后勤或旅商换取结算币。
也可以保留在后勤仓库中收藏。

有些异常回收物看起来像零件。
有些不像。
后勤部会试图给它们估价，尽管很多东西不该有价格。

### 简短说明

> 异常回收物：不能救命，但可能值钱。也可能只是很怪。

---

## 17.5 珍贵度定义

珍贵度用于表示物品的价值、稀有性和收藏意义。
珍贵度不一定等于战斗强度。
尤其是异常回收物，越珍贵不代表越有用，可能只是越不该被捡回来。

| 珍贵度 | 定位   | 说明                     |
| --- | ---- | ---------------------- |
| 一般  | 常见物  | 普通回收物，价值较低，常用于出售       |
| 稀有  | 少见物  | 带有异常性质或特殊来源，价值较高       |
| 珍贵  | 高价值物 | 有明显异常、历史或风险价值，适合收藏     |
| 唯一  | 档案物  | 独一份或高度异常，建议保留进入收藏 / 图鉴 |
