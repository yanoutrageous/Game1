# Base Art 工作区规范

`D:\AGAME1\Base Art` 是 Game1 / GraytailGodot 的原始美术制作区和 staging 区，不是 Godot runtime assets。

## 允许内容

- prompt 与生成参数记录。
- GPT 或其他授权工具生成的原始图。
- 候选图、筛选图和评审记录。
- 切割前文件、切割工作文件和动效源文件。
- 准备交给程序评估的 runtime candidates。

## 禁止内容

- Godot `.import`、`.uid`、`.godot` 等导入副产物。
- 未经授权直接复制的 `Base Docs` 图片。
- 直接可运行的 `res://` 路径引用。
- 未登记来源、未评审、直接作为最终图使用的文件。

## 状态流

`raw_generated -> selected -> cut_working -> runtime_candidate -> exported -> manifest_registered -> godot_imported`

进入 `manifest_registered` 和 `godot_imported` 前，资产仍然只是制作区或候选区内容，不应被 Godot 或 AssetCatalog 直接引用。

## 目录边界

- `Base Docs`：设计和参考来源，不向本目录批量复制图片。
- `Base Art`：原始制作、候选、切割和导出候选区。
- `Connection`：程序与美术交接层，只放请求、清单、反馈和模板，不堆放大批原图。
- Godot runtime assets：真实运行时资产，只能通过后续 manifest-backed 流程进入。
- 仓库 `docs/art`：保存工作流边界镜像说明，不替代本目录 registry。

## Git 规则

`Base Art` 默认不进入普通 git。真实图片、源文件和候选图应先完成来源登记、授权判断、评审和导出确认，再由后续阶段决定是否进入 runtime pipeline。
