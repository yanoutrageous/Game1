## 6. 客观剩余风险

- 历史封存验证器仍含旧分支、旧全局 manifest 哈希与旧信号名假设；它们不适合作为 ART25 总门禁。真实内部保护集均已单独通过，但包装器债务应由后续治理任务统一版本化，避免继续累积。
- Godot 主路由锚点探针退出时仍可能报告历史 `ObjectDB instances leaked at exit` 警告；退出码与断言为 0，本阶段未引入持久节点或循环加载路径。该警告应作为程序侧技术债继续追踪。
- ART25 新内容采用稳定 visual key 和单一可重建生成器，后续正式手绘资产可以一对一替换；替换时仍需重跑哈希、预算、五分辨率矩阵和同一冻结视觉标准。

以上风险不构成本阶段美术交付阻断，也没有被描述为已经修复。
