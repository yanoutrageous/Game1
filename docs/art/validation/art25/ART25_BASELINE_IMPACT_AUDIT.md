## 3. 失败分类规则

- `VISUAL_DEFECT`：真实生产画面不满足冻结标准。
- `ART_BINDING_GAP`：接口存在但图像解析为错误内容或 fallback。
- `PROGRAM_ROUTE_GAP`：无法在生产路径稳定进入或维持状态。
- `EVIDENCE_ONLY`：实现存在但没有符合最终标准的新鲜 Computer Use 证据。
- `REGRESSION`：破坏已通过状态。

执行时只直接修改前两类；程序路径缺口形成独立接口记录。
