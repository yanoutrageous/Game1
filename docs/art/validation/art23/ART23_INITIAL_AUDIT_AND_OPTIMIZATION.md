# ART23 审计、返工与两轮优化记录

## 首次完整审计

证据：`screenshots/optimization_evidence/art23_initial_audit_27_pages.png`。

27 个二级页均存在且家具映射正确，真实主线路由通过。首次审计发现四个跨页问题：说明文字与阴影/横线叠加导致发糊；底部元信息越过 248 px 羊皮纸边界；左下标签与拉杆底座分离；一级切换缩放围绕左上角而非中央家具。

第一次 Computer Use 预验收还发现透明的中央模块容器截获顶部点击。修复为容器忽略鼠标，并加入运行时命中断言。第二次预验收逐页走完 27 页后发现：“设置外观”进入外观配置，再收起/展开会错误回到抽奖结果页。修复为在收起时保存一级/二级上下文，展开时精确恢复，并加入自动回归断言。两次预验收均判定失败，没有写成完成结论，也没有 push。

## 优化一：布局、同步动效与基础可读性

证据：`screenshots/optimization_evidence/art23_optimization_round1_27_pages.png`、`art23_optimization_round1_goals_task.png`、`art23_optimization_round1_collapsed.png`。

- 标题缩至安全宽度，把只读/封存元信息移到标题右侧。
- 正文移除阴影，卡片上移，底部保留安全边距。
- 重画 152×100 拉杆：底座延伸到标签区域，文字进入底座。
- 模块组 pivot 改为中央区域；二级切换让羊皮纸、标题、正文、元信息和卡片同步淡入，消除文字独立漂浮。
- 隐藏图鉴原生灰色水平轨道，同时保留焦点自动滚入。

复审结果：27/27 静态页面无裁切，收起态完整展示档案室。

## 优化二：ART22 连续性、选中态与字体层级

证据：`art23_style_unification_r0.png`、`art23_style_unification_r1.png`、`art23_style_unification_r2.png`、`art23_font_hierarchy_r1.png`。

- 客观对照 ART22 后确认初版材质、亮度和控件轮廓割裂；保留“房间 + 家具打开”的长期系统结构，但把导航、页签、羊皮纸、卡片、锁链和档案牌统一到 ART22 的黑铁、深木、暖金、旧羊皮纸和青绿选中态。
- 重做档案室背景的明暗层次：暖灯负责可居住感，青蓝深处负责危险感；角色继续复用同一游戏的八帧资源，并用地面阴影把角色落在房间中。
- 修正 hover/focus/pressed 覆盖 selected 的问题，选中的一级、二级和卡片在键盘焦点下仍保持青绿语义。
- 复查确认全像素字体会让正文和右侧数据发虚、疲劳。短按钮、一级/二级页签和短卡片标签继续使用 FusionPixel；页面标题、说明、元信息、等级与统计改用 Noto Sans CJK SC Regular，正文提升到 16 px，保留无重描边的清晰边界。

## 最终验收前的追加缺陷与修复

静态复审后，Computer Use 的后续完整轮次又发现三类仅靠截图矩阵不能覆盖的问题：

- 图鉴怪物/藏品空数据卡片曾落入英文 `Unknown`。修复为按页面语义给出中文“未发现/未登记”占位，不伪造后端结果。
- 键盘焦点进入内容卡片后，Esc 曾跳过二级/一级层级。为一级按钮、二级页签和内容卡片补齐显式焦点归属与返回目标。
- 收起状态下单次 Esc 曾直接返回主菜单。单纯增加防抖不能解决根因；最终把取消输入从 `_unhandled_input` 提升到 `_input`，保留 600 ms 防抖，并在运行时 runner 中覆盖“接受→拒绝抖动→再次接受”序列。

每一轮发现问题后均停止验收、修复并从真实主菜单按同一冻结标准重新开始，没有把局部复验冒充全量通过。

## `ART23-CU-FROZEN-2` 最终 Computer Use 结果

最终轮在代码冻结后完成，结果为 27/27 PASS。图鉴末页自动滚入、右侧外观入口、收起/展开精确上下文、三次以上一级快速切换、键盘一级→二级→卡片与 Esc 卡片→二级→一级→主菜单均通过。连续观察 60 秒看到了角色不同姿态与眨眼帧、回归常态、环境光和低密度粒子，正文与卡片没有独立漂移。最终结论记录在 `docs/validation/ART23_LONG_TERM_FINAL_UI_VALIDATION.md`。
