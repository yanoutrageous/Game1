# ART24 首轮实现审计

- 审计批次：`ART24-FIRST-AUDIT-1`
- 审计对象：首轮 1280×720 全量状态矩阵（8 个一级模块、54 个二级状态）
- 审计结果：`REWORK_REQUIRED`
- 结构约束：不得改变左侧扫描/状态栏、中央局内区域、右上协议牌、底部键位栏以及既定模态层级。

## 已通过项

1. 六类既有房间背景采用等比 cover 裁切，未拉伸，视觉风格与项目一致。
2. 左栏、协议牌、底栏、全屏地图、背包、地面物品、提示/确认、结算八个一级模块均能渲染。
3. E/Q/G/M/Tab/Space/J/T/Esc 与当前 Godot 输入契约一致。
4. 地图为全屏阻断层；背包与地面物品保持在局内内容区，左栏保留，协议牌仍可见。
5. 角色、怪物与世界掉落资产具备动作/状态帧，未退回静态占位图。
