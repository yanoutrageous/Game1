# ART22 出发探索动效审计

状态：实现完成，等待冻结标准下的最终 Computer Use 验收。

## 审计结论

原实现加载了 8 张哈希不同、姿态不同的 ART21 角色帧，但以 0.18 秒等间隔顺序轮播。问题因此不是“文件只有两张”，而是呼吸、眨眼、摆尾和侧身观察被当作同一频率的连续动作，形成快速姿态跳变，主观上接近两帧闪烁。

ART22 将角色拆成两条节奏：

- 常驻呼吸 / 眨眼使用 0–5 帧和约 0.34 秒节拍，序列中保留静止帧和恢复帧。
- 侧身观察使用 6–7 帧，只在首次约 5 秒后触发，随后约 10 秒一次，节拍约 0.42 秒。

环境动效不重新生成整张背景，而是复用已受 manifest 管理的 ART21 火焰 / 烟雾小帧，并精确挂在 ART22 干净背景已有光源上。第一版目测定位曾产生悬空橙色光球，已拒收；最终位置根据 1280×720 干净背景重新定位并缩小、降透明度。

## 验收风险

- 动效必须附着在灯具、蓝焰、烟源和悬挂结构上；任何悬空亮斑均为失败。
- 角色侧看不能使脚底脱离接触阴影，不能扩大角色占比或侵入羊皮纸。
- 展开态的环境动效大多被羊皮纸自然遮挡；收起态才是完整环境动效展示面。
- 粒子只提供深度，不承担信息表达；不得穿透到文字层或弹窗层。
- Computer Use 必须连续观察至少 12 秒，不能用单张截图替代节奏验收。
