# ART24R2 最终 Computer Use 验收标准

- 标准 ID：`ART24R2-FINAL-CU-FROZEN-1`
- 冻结日期：2026-07-19
- 冻结时点：最终完成审计启动前，两轮问题驱动优化完成后。
- 事实源：当前分支 Godot 生产 `project.godot`、真实 G41/M6 快照与命令接口。
- 视觉参照：UE 原型的空间权重、角色尺度、战斗反馈顺序与房间氛围。
- 禁止替代：旧 Godot 画面和 ART24 preview runner 不得作为视觉通过证据。

## 1. 验收方法

1. 最终验收必须由 Computer Use 操作独立 Godot 游戏窗口完成。
2. 必须从主菜单进入出发页，再进入真实局内；不得直接用 preview runner 代替生产入口。
3. QA 诊断入口只允许播种真实快照、移动到真实房型或补齐难以稳定复现的容量数据；被验收的控件、场景实体、动画和结算页必须仍是生产节点。
4. 61 个二级状态逐项记录 `PASS` 或 `FAIL`。不得使用 `MISSING`、`预计可用` 或自动化通过代替视觉通过。
5. 任何一项 `FAIL` 均阻止完成、提交和 push；返工后必须在同一冻结标准下重新验收。

## 2. 全局通过条件

- 1280×720 逻辑画面内，左栏、中央房间、右上协议和底栏均完整，无裁切、互相覆盖或点击区漂移。
- 中央房间始终是最大且最强的视觉主体；上下文悬浮窗不压成一级模态。
- 玩家可移动，角色与怪物脚底关系、尺度和遮挡可信；生产碰撞不依赖贴图尺寸。
- 玩家可见文本不暴露事件 ID、`running`、`Normal`、`runtime authority`、原始日志或英文调试标签。
- 选中、禁用、容量阻塞、危险确认和主要操作具有可辨识的颜色与边框层级。
- 打开/关闭/返回关系可逆；关闭背包、地图、事件、暂停和撤离后回到同一局内状态。
- 未知素材只允许进入统一 fallback；已知物品和怪物不得使用错误类别图标或程序几何占位。

## 3. 一级模块与二级状态

以 `art24_state_catalog.gd` 和两份 ART24 acceptance CSV 的 61 个唯一 `secondary_id` 为封存清单：

- `room`：26 项。普通、雷险、箱子、事件、怪物、撤离房的进入、过程、完成、重复开合和空状态均须通过。
- `protocol`：5 项。等级 5→1 的颜色、风险和文字均须可辨识且不压框。
- `map`：4 项。总览、选格、标记、可返回均须完整落在地图框内。
- `inventory`：5 项。空、已有物品、选中、满载、详情均须使用真实物品图标和真实容量。
- `loot`：8 项。地面可见、近距单件/多件、拾取、容量阻塞、替换选择/确认、离开隐藏均须通过；生产奖励不得打开整屏回收页。
- `overlay`：5 项。教学、事件、暂停、安全撤离、风险撤离均须通过。
- `result`：6 项。成功、失败保全待选/已选/容量阻塞、失败最终、主动放弃均须通过。
- `motion`：2 项。完整动效与减弱动效均须保留信息，不得改变布局或规则。

## 4. 战斗与动效专项

- 至少复验水平/垂直移动、idle、攻击、受击、怪物出现/警戒/攻击/受击/击败。
- 玩家移动循环必须使用四步表现序列；攻击使用四阶段素材；不得退化为单帧或仅两帧来回闪烁。
- 默认怪物使用 UE/既有资源；已生成怪物作为 `art24_generated` 变体可替换，切换变体不得改变 HP、最大 HP、状态、碰撞、行为或掉落。
- 战斗激光、弹射物、门封和拾取反馈不得越过中央房间污染左栏、右上协议或底栏。
- 实机移动与战斗不得出现可见的周期性停顿、追帧跳跃或输入锁死。

## 5. 掉落、箱子与结算专项

- 物品首先作为地面实体显示；靠近才出现悬浮窗，离开必须自动隐藏且移动不被暂停。
- 箱子靠近才显示操作；首次打开只生成一次内容，随后可关闭、重开、部分拾取并保留剩余，清空后显示空箱。
- 成功/失败/放弃结果只显示玩家可理解的指标和摘要；不得显示原始事件/交易日志。
- 失败保全候选、重量、4 点容量、超重禁用和确认按钮必须完整可读。
- 最终结果操作区只显示两个真实按钮且等宽，不得出现假按钮槽。

## 6. 自动化与仓库门禁

Computer Use 视觉通过后，还必须全部满足：

- G41 固定步长/插值/暂停/怪物/箱子/掉落/激光边界回归通过。
- ART24 8 个一级模块、61 个二级状态与 33 个必需视觉键通过。
- 世界上下文、地图五分辨率、地图真实场景、结算六状态真实场景探针通过。
- M6 出勤、局内、失败保全和结算逻辑通过。
- `project.godot`、全局资产清单和 `.translation/.import/.uid` 生成副作用清理完毕。
- 工作树不包含未解释的 Godot 生成文件；合法新增测试场景与美术资源进入明确提交范围。

只有以上所有条件同时通过，ART24R2 才能标记完成并进入 commit/push。
