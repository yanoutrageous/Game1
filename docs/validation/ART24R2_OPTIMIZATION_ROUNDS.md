# ART24R2 两轮问题驱动优化记录

状态：两轮执行完成，等待最终冻结标准下的完成审计。

## 不变的核心结构

- 左侧固定区域扫描、生命/资源、目标与背包摘要。
- 中央房间为主视觉；角色、怪物、箱子和掉落均属于房间世界。
- 右上固定协议、压力与风险信息。
- 底部固定生产按键条；背包、地图和结算是模态，掉落与箱子是近距上下文。

## 第一轮：真实接口、结构与布局

问题：G41/M6 新状态尚未完整进入 ART24；战斗显示存在重复快照和静态写入；世界掉落、箱子、背包、地图和结算的层级与尺寸不稳定。

执行结果：

- 接入 G41/M6 的真实装备、消耗品、临时申领、活动局与失败保全字段。
- 战斗改为固定模拟与显示插值分离，减少重复深拷贝和每帧重建。
- UE/已有怪物素材作为默认表现；已生成的 slime、bat、drone 全套动作保留为 `art24_generated` 可切换变体，变体不改变数值、碰撞、行为和掉落。
- 地面物品改为房间实体；靠近后显示紧凑悬浮窗，离开后隐藏。箱子复用同一近距上下文，可重复开关且首次内容只生成一次。
- 背包接入 43 个真实物品映射；空包使用低透明度背包水印，不伪造槽位。
- 地图尺寸由集中布局计算器控制，并增加五档分辨率的真实场景探针。
- 成功、失败、放弃与失败保全改为同一正式结算框架；失败保全选择、超重阻塞和确认进入一等状态。

复验：G41、ART24 61 状态、世界上下文、地图布局/场景、结算场景探针均通过。

## 第二轮：实机层级、玩家语言与反馈收口

问题：Computer Use 实机暴露出暂停按钮漂浮、事件/撤离使用内部字段、激光穿出房间、结算操作区存在假空槽，以及生产搜索/旧战斗/事件仍会额外打开整屏回收结果页。

执行结果：

- 暂停层补齐正式框体、内容高度和主要/次要/危险按钮层级。
- 事件类型与选项由表现层映射为玩家语言，不修改事件 ID 与命令接口。
- 撤离确认改为收益、背包和遗留物资摘要；确认与取消形成明确层级。
- 主动放弃二次确认、活动局限制和无活动局提示全部去除英文内部说明。
- 战斗激光裁剪在房间边界内，使用三层能量线、枪口与边界命中反馈；增加数学边界回归。
- 最终结算的两个真实操作按可用宽度等分；连续底板替代绘有三个槽位的旧贴图，消除假空槽。
- 生产搜索、旧战斗和事件奖励不再强制打开整屏回收页，只给短暂反馈；真实物品继续落地并通过近距悬浮窗处理。整屏回收页仅保留为开发诊断工具。

复验：Computer Use 已通过暂停、事件、撤离、成功、失败、失败保全和最终操作区；自动化增加“生产奖励不得重新打开阻塞式回收页”守卫。
