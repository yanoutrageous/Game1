# M7-0：当前已有实例内容基线说明

文档状态：M7 开始前的阶段性事实基线
事实截止：2026-07-19，当前工作分支提交 `2fd9d4d2a7594f2d6c87e01b7eb227c6f3dfd788`
程序基线：ART23 + G41 + M6；ART24 / ART24R1 不属于本基线
文档用途：把仓库当前已有的局内、局外实例统一写入策划案，作为 M7 增量判断、验收和回归依据。

> 本文记录“当前已经存在什么”，不代表 M7 已经完成。凡标为预览、锁定、保留接口或调试的内容，均不能在验收时算作真实玩法。

## 1. 判定口径

| 状态 | 策划含义 | 是否能算作当前有效内容 |
|---|---|---:|
| 真实可玩 | 玩家可以通过正常流程触发，结果会改变本局状态 | 是 |
| 真实持久 | 结果能在最终结算后写入存档，重开后仍存在 | 是 |
| 真实只读 | 展示的是已经产生的真实数据，但当前页面不能修改它 | 是，但不能算作完整功能 |
| 展示预览 | 有页面、卡片、文案或按钮，但不会执行对应规则 | 否 |
| 锁定保留 | 明确为以后开放，当前不能获得或使用 | 否 |
| 调试专用 | 只用于自动化或人工验证，不属于玩家内容 | 否 |

同一个内容可能同时具备多种状态。例如“历史战绩”是由真实结算持久化的数据，在长期系统中以真实只读方式展示。

## 2. 当前玩家实际闭环

当前能够完整成立的主循环是：

1. 在出发探索页查看仓库中的真实物品实例。
2. 手动配置最多 2 件装备和最多 3 件携入消耗品；同一装备部位不能重复。
3. 开始 10×10 标准探索，或进入独立的 5×5 教学验证局。
4. 在房间中移动、搜索、开箱、战斗、处理事件、拾取或替换实际掉落物。
5. 找到撤离点后成功撤离，或因生命耗尽失败，或主动放弃。
6. 成功时把非消耗品和金币结算进仓库；失败时先选择可抢救物品再确认；放弃时不抢救。
7. 结算生成历史记录，长期系统的个人资历页可以只读查看。

当前尚未成立的闭环是：

- 玩家不能真正选择八档地图与难度；当前只有固定的 10×10 标准局可作为正式探索。
- 玩家不能接取并完成真实委托，也没有任务、成就的真实进度与领奖。
- 玩家不能通过基地商店购买物品，也不能在仓库中正式出售普通藏品。
- 研究、资历升级、图鉴发现、收藏套组和红点尚未形成长期成长闭环。

### 3.3 当前基础生存与压力规则

- 基础生命为 100，基础战力为 5。
- 触雷基础伤害为 30，装备减伤后仍至少受到 5 点伤害。
- 探索、触雷和机关失败都会提高协议压力；压力会跨越 5 至 1 的协议阶段。
- 基础背包容量为 10 重量；失败基础抢救容量为 4 重量。
- 本局黑币是风险资产：成功撤离按 1:1 转为局外金币，失败或放弃时丢失。
- 当前标准局的普通搜索额外获得 1 黑币，这是现有标准局的真实规则修正。

## 7. 局外仓库、携入与经济实例

### 7.1 新存档初始仓库

新存档会获得 6 个真实物品实例：

- 护目镜 ×1
- 绝缘套 ×1
- 压缩饼 ×2
- 胶带卷 ×1
- 扫描针 ×1

旧存档迁移时只会补齐缺失的这一批固定初始实例一次，不会每次读取都重复赠送。

### 7.2 当前真实携入规则

- 最多配置 2 件装备。
- 同一装备部位不能重复配置。
- 最多配置 3 件消耗品。
- 装备不占局内背包重量；携入消耗品占背包重量。
- 配置必须由玩家手动完成，当前没有自动推荐或自动替换。
- 每局还可以领取 1 份临时应急压缩饼；它不属于仓库实例，且终局清除。

### 7.3 当前真实与缺失的局外经济

| 内容 | 当前状态 |
|---|---|
| 金币存档 | 真实持久；新存档为 0 |
| 成功撤离获得金币 | 真实持久；本局黑币按 1:1 转换 |
| 结算物进入仓库 | 真实持久；按物品实例写入 |
| 申领应急压缩饼 | 真实可玩；每局一次，临时物品 |
| 基地购买急救物或装备 | 展示预览；不会扣金币，也不会生成仓库实例 |
| 仓库出售普通藏品 | 尚未实现 |

## 8. 结算与历史实例

### 8.1 成功撤离

- 背包内的装备、藏品、怪物材料和特殊材料进入仓库。
- 所有消耗品清除。
- 本局黑币按 1:1 转为金币；本局已直接获得的金币保留。
- 生成一条独立的结算历史记录。

### 8.2 探索失败

- 先生成只读的可抢救物品池，不立即改写局外仓库。
- 玩家在抢救重量内选择非消耗品，确认后才写入仓库。
- 所有消耗品与本局黑币丢失；本局已直接获得的金币保留。
- 同一结算结果只能提交一次。

### 8.3 主动放弃

- 需要强确认。
- 抢救容量为 0，背包物品和本局黑币全部丢失。
- 本局已直接获得的金币保留，并生成放弃历史记录。

### 8.4 历史记录

- 最多保留最近 50 条成功、失败和放弃记录。
- 历史记录保存结算当时的快照，不会因为玩家后来出售或配置仓库物品而被改写。
- 当前进程内可以从局内返回出发探索页并继续同一局；关闭程序后恢复进行中探索尚未实现。

## 9. 资历与天赋接口的当前边界

存档已经保留资历等级、资历经验、作业许可、协议难度、天赋点和天赋标记的位置。新存档初始为：资历 1 级、经验 0、许可 1 级、协议难度 5、天赋点 0。

代码还定义了 6 个可生效的方向：携行整备（背包 +1）、抢救条款（抢救 +1）、抗冲击训练（触雷减伤 5）、压力读数（压力增长减少 2）、旅商笔记（安全收益 +1）、扫描纪律（扫描提示 +1）。

但当前没有玩家可用的天赋获得、升级、消费或配置流程。因此这些只是可被测试标记激活的程序接口，不能作为已经实装的长期成长内容。
