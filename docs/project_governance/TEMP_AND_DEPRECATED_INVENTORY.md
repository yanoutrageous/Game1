# 临时与过期文件登记

本文件是 G20-R3d2 新增的临时 / 过期 / 历史候选登记。它只登记，不移动、不重命名、不删除、不清理、不归档任何文件。无法确认当前用途的条目统一标记为 `needs review`。

## 规则

- `action_allowed` 默认是 `no action in G20-R3d2`。
- 如未来需要处理候选文件，`action_allowed` 必须改为 `requires user authorization` 并等待单独授权。
- 涉及删除、移动、重命名、归档、批量清理、外部路径处理或图片入库时，`requires_user_authorization` 必须为 `yes`。
- `recommended_name` 和 `recommended_location` 只是后续整理建议，不代表已授权执行。
- 本文件不修改 R3d1 的 `BRANCH_INVENTORY.md`、`COMMIT_MILESTONE_MAP.md`、`VALIDATION_STATUS_MATRIX.md` 正文。
