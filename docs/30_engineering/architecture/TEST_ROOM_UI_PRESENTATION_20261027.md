## 现场诊断与取舍

已用真实鼠标从 Main→设置→进入隔离测试场，观察固定场景标识。原房间图片已具有墙/地/门材质，但外围再次放大整张图片，重复门和道具形成虚假的第二层场景；玩家没有与敌人一致的独立接触阴影。HUD 的扫描图、过高的短状态区、空背包区和底部操作框缺少统一间距。背包模态存在外框加四个完整内框，视觉重量超过内容；展开地图又采用另一套偏冷的边缘。

方案比较：全部重画/引入新视觉系统超出一间样板范围；只叠透明层不能解决重复框体和排列。本轮选择保留房间原图、阴影素材和组件身份，整理背景与局部层次、重排既有信息、把模态内部重框改为薄分隔，沿用明确信息/危险/焦点通道。此为本轮实现取舍，不称为用户原话。
