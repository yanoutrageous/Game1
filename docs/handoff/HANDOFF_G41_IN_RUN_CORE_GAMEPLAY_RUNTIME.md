## 权威边界

- 物品位置：只由 `RunAssetLedger` 写入。
- 活跃战斗：只由 `G41CombatSimulation` 写入，外层调度只推进固定 tick。
- 持久局内 HP、清房、奖励、逃跑和失败：CommandBus → RoomResolver → Rule/Effect。
- UI、HUD、交互实体和房间视图：只读快照与命令请求，不直接修改事实。
