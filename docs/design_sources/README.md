# Design Sources

`docs/design_sources/` stores versioned repository copies of selected text planning sources that were imported during G20-R3a from `D:\AGAME1\Base Docs`.

The external Base Docs originals remain at `D:\AGAME1\Base Docs`. They are creative source files and were not modified, moved, renamed, deleted, or overwritten by G20-R3b.

These repository copies are for engineering handoff, traceability, review, and controlled planning. They are not direct implementation checklists. Any gameplay, Godot, data model, UI, or asset work still requires a separate implementation plan and validation boundary.

PNG visual references from Base Docs are not imported in G20-R3a/R3b. They are only registered as `external_reference / pending_user_authorization`; no `reference_images/` directory exists in this batch.

Use `docs/design_sources/DESIGN_SOURCE_INDEX.md` for the current imported text source index.
